# Workflow: graphify

Follow the workspace graphify skill installed at `.agents/skills/graphify/SKILL.md` to navigate, query, or rebuild the knowledge graph.

### Quick Actions:
- **Rebuild AST Graph:** `graphify update .`
- **Rebuild Collapsible Tree:** `graphify tree`
- **Query Architecture:** `graphify query "<question>"`
- **Inspect Symbol:** `graphify explain "<symbol>"`
- **Trace Shortest Path:** `graphify path "<source>" "<target>"`
- **Open Visuals:** `powershell .agents/skills/graphify/scripts/open-graph.ps1`
